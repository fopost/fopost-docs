## List items

```http
GET /v1/inbox
```

```bash
curl "https://api.fopost.com/v1/inbox?workspace_id=7d2b8c11-4e5a-4a8f-b0d9-3c5e6f7a8b90&state=unread" \
  -H "X-API-Key: $FOPOST_API_KEY"
```

| Parameter | Description |
|:----------|:------------|
| `workspace_id` | One workspace. Omit it to span every workspace the key can reach; each item then carries `workspace_id` |
| `type` | `comment`, `mention`, `review`, or `dm` |
| `state` | `unread`, `read`, `resolved`, or `snoozed` |
| `platform` | A platform slug, such as `instagram` |
| `account_id` | One connected account |
| `post_id` | Comments under one FoPost post |
| `post_external_id` | Comments under one platform post, including posts you did not publish through FoPost |
| `conversation_id` | One DM thread |
| `direction` | `inbound` or `outbound` |
| `q` | Searches text and author |
| `sort` | `newest` (default), `oldest`, or `unanswered` |
| `page`, `per_page` | Pagination, `per_page` up to 100 |

An item looks like this:

```json
{
  "id": "0f1c4a1e-8f3c-4c62-9f6a-2a4b1a9e77d1",
  "workspace_id": "7d2b8c11-4e5a-4a8f-b0d9-3c5e6f7a8b90",
  "platform": "instagram",
  "type": "comment",
  "state": "unread",
  "direction": "inbound",
  "author_name": "Sam Rivera",
  "author_handle": "samrivera",
  "text": "Does this come in blue?",
  "permalink": "https://www.instagram.com/p/abc123/",

## Direct messages

Start a conversation:

```http
POST /v1/inbox/conversations
```

| Field | Description |
|:------|:------------|
| `account_id` | The account to send from, with `handle` |
| `handle` | Who to message. Available on accounts whose `can_start_conversation` is true |
| `comment_id` | An inbox comment to answer privately instead of `account_id` and `handle`. This is how Facebook and Instagram open a DM, and it needs `can_private_reply` on the comment |
| `text` | The message |
| `media_ids` | Optional files from the media library, where the platform takes them |

```bash
curl -X POST https://api.fopost.com/v1/inbox/conversations \
  -H "X-API-Key: $FOPOST_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "comment_id": "0f1c4a1e-8f3c-4c62-9f6a-2a4b1a9e77d1", "text": "Sending you the details here." }'
```

The response is `201` with the `conversation_id` where the platform reports one and the sent `item`.

React to a message, or remove your reaction with `null`, where `can_react` is true. Instagram has one reaction, a heart, so any emoji sends it.

```http
POST /v1/inbox/{id}/react
```

```json
{ "reaction": "❤️" }
```

Show the typing indicator in a thread while someone writes an answer, then clear it with `on: false`:

```http
POST /v1/inbox/conversations/{conversationId}/typing
```

```json
{ "account_id": "b81e4f02-91a3-4c55-8de6-77a0c1f2d3e4", "on": true }
```

All of these need the `publish` scope.

## Replies awaiting approval

An automation or the agent can draft a reply that a person still has to send. Nothing reaches a platform until it is approved.

```http
GET /v1/inbox/approvals
POST /v1/inbox/approvals/{id}/approve
POST /v1/inbox/approvals/{id}/reject
```

Approve takes an optional `text` to send an edited version instead of the draft. A `409` means the reply was already decided.

## Coverage

```http
GET /v1/inbox/accounts
GET /v1/inbox/platforms
GET /v1/inbox/unread-count
```

`/accounts` lists every active connected account with `inbox_supported` and `dm_supported`, so a filter can tell the truth about what it reads, plus `can_start_conversation` for accounts that can open a DM by handle. An account with `reconnect_required: true` was connected before the inbox asked for a permission it needs and is not polled until someone reconnects it; everything else that account does keeps working. `/platforms` lists which networks feed the inbox today and which are coming.

## Poll now

```http
POST /v1/inbox/refresh
```

Fetches new comments and messages for every inbox-capable account in the `workspace_id` you pass, instead of waiting for the next scheduled poll. The response reports how many accounts were polled and how many new items arrived. Platforms that bill per read are read on this call, so use it when someone is waiting, not on a timer of your own.
