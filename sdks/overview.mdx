Every client here is a thin wrapper over the [REST API](/api/overview). The platform APIs, formatting, media handling, retries, and scheduling all run on our side, so an SDK stays small and gains new networks without you upgrading anything.

```
Your app  →  SDK  →  api.fopost.com  →  the networks
```

## Cloud clients

These talk to your FoPost account with an API key.

## Framework integrations

Each one wraps the client for its language and adds the wiring that framework expects: configuration, dependency injection, background jobs, console commands, and a signature-verified webhook endpoint. None of them adds to the API surface, so the language SDK's page stays the reference for resources and errors.

| Integration | For | Install |
|:------------|:----|:--------|
| [Laravel](/sdks/laravel) | Laravel 10, 11, 12 | `composer require fopost/laravel` |
| [Symfony](/sdks/symfony) | Symfony 6.4 LTS, 7.x | `composer require fopost/symfony-bundle` |
| [Rails](/sdks/rails) | Rails 7.0+ | `bundle add fopost-rails` |
| [Django](/sdks/django) | Django 4.2 to 5.2 | `pip install fopost-django` |
| [FastAPI](/sdks/fastapi) | FastAPI 0.110+ | `pip install fopost-fastapi` |
| [Spring Boot](/sdks/spring) | Spring Boot 3, Java 17 | `com.fopost:fopost-spring-boot-starter` |
| [ASP.NET Core](/sdks/aspnet) | .NET 8, .NET 9 | `dotnet add package FoPost.AspNetCore` |
| [Next.js](/sdks/nextjs) | Next 14, 15 | `npm install @fopost/next` |
| [WordPress](/sdks/wordpress) | WordPress 6.4+ | Plugin install |

## Automation & tooling

For publishing from somewhere that is not your application code.

| Tool | For | Install |
|:-----|:----|:--------|
| [CLI](/cli) | Your terminal and shell scripts | `brew install fopost/tap/fopost` |
| [GitHub Action](/sdks/github-action) | A GitHub workflow | `uses: fopost/fopost-github-action@v0` |
| [Terraform Provider](/sdks/terraform) | Workspaces, labels, webhooks, automations as code | `fopost/fopost` |
| [Zapier](/sdks/zapier) | Zapier Zaps | Private app |
| [n8n](/sdks/n8n) | n8n workflows | `n8n-nodes-fopost` |
| [Make](/sdks/make) | Make scenarios | Private app |
| [Browser extension](/sdks/browser-extension) | Networks with no write API | Chrome Web Store |
| [`@fopost/mcp`](/sdks/mcp) | Any MCP client | `npx -y @fopost/mcp` |

Zapier and Make review custom apps by hand before they appear in a public directory, and both integrations are private apps until that happens. Their pages say how to install one today.

## Another language

The REST API is plain JSON over HTTPS with one header, so a language with no official client is still one request away:

```bash
curl -X POST https://api.fopost.com/v1/posts \
  -H "X-API-Key: $FOPOST_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "workspace_id": "7d2b8c11-4e5a-4a8f-b0d9-3c5e6f7a8b90",
    "accounts": ["3a9f1d20-6c77-4b2e-9a01-8f5d2c3b4e10"],
    "content": [{ "text": "Hello from anywhere." }]
  }'
```

The [OpenAPI spec](https://api.fopost.com/v1/openapi.json) generates a usable client in most languages. If you want an official one for a language that is missing, [tell us which](https://fopost.com/contact); demand is how the order gets decided.

## Not the self-hosted library

There is a separate, free PHP library that talks to each network from your own server with your own app credentials. It is not part of the Cloud and is documented in its own repository; everything on this page publishes through your FoPost account instead.
