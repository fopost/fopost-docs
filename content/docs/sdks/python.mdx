`fopost` is the official Python client. It is built on `httpx` and `pydantic` v2, fully typed, and needs Python 3.10 or newer.

```bash
pip install fopost
```

<Callout type="warn">
This is a 0.x release. The surface is still settling and a minor version may
break something. Pin an exact version if that matters to you.
</Callout>

Source and issues: [github.com/fopost/fopost-python](https://github.com/fopost/fopost-python). MIT licensed.

## Quick start

```python
from fopost import Fopost

client = Fopost()  # reads FOPOST_API_KEY, or pass api_key=

workspace = client.workspaces.list()[0]
accounts = client.accounts.list(workspace_id=workspace.id)

post = client.posts.create(
    workspace_id=workspace.id,
    content="Hello from Python 🦉",
    accounts=[a.id for a in accounts],
)

client.posts.publish(post.id)
```

`publish` returns once delivery is queued, not once it is live. Read `client.posts.deliveries(post.id)` or subscribe to [webhooks](/api/webhooks) for the result.

## Threads and media

`content` takes a string for a single post, or a list for a thread:

```python
client.posts.create(
    workspace_id=workspace.id,
    content=[
        "First post in the thread",
        {
            "text": "Second one, with an image",
            "media": [
                {"type": "image", "name": "chart.png", "url": "https://.../chart.png"},
            ],
        },
    ],
    accounts=[a.id for a in accounts],
)
```

## Schedule instead

```python
client.posts.create(
    workspace_id=workspace.id,
    content="Doors open Monday.",
    accounts=[accounts[0].id],
    status="scheduled",
    schedule_at="2026-09-02T09:00:00Z",
)
```

Times are UTC.

## What is on the client

| Namespace | Methods |
|:----------|:--------|
| `client.posts` | `list`, `iter`, `iter_pages`, `get`, `create`, `update`, `delete`, `publish`, `cancel`, `retry`, `preflight`, `deliveries` |
| `client.accounts` | `list`, `get`, `health` |
| `client.workspaces` | `list`, `get` |
| `client.labels` | `list` |
| `client.ai` | `credits`, `generate_caption`, `rewrite`, `repurpose_url` |

`client.posts.iter()` walks every page for you, so you do not hand-roll a
pagination loop to sweep a workspace.

<Callout type="warn">
On `client.ai`, only `credits` and `generate_caption` work with an API key
today. `rewrite` and `repurpose_url` reach endpoints that require a dashboard
session and will answer `401`. Use the composer for those until a later
release.
</Callout>

## Errors

Failed requests raise a typed exception carrying the status and the API's
`error` code. A `402` means the usage credit ran out (add a payment method) and should not be retried; a
`429` carries the seconds to wait.
