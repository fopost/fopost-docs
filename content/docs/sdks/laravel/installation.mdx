# Laravel Installation

## Requirements

- PHP 8.1 or newer
- Laravel 10, 11, 12, or 13

No FoPost account is required. The package wraps the [PHP library](/developers) and publishes with credentials you hold.

## Install

```bash
composer require fopost/fopost-social-laravel
```

The service provider is auto-discovered. `fopost/fopost-social-core` comes with it.

## Publish the config

```bash
php artisan vendor:publish --tag=fopost-config
```

This creates `config/fopost.php`, which reads from `.env` and lists every supported variable.

## Add credentials

Put the credentials for the networks you want in `.env`. Telegram is the quickest to verify:

```dotenv
TELEGRAM_BOT_TOKEN=your-bot-token
TELEGRAM_CHANNEL_USERNAME=@your_channel
TELEGRAM_PARSE_MODE=HTML
```

Only networks with valid credentials are registered. Leaving X blank means X is not available, rather than failing when something tries to publish to it.

The full set of variables is on [Configuration](./configuration), and what each network needs is on [Configure Credentials](/developers/getting-started/connect-platforms).

## Verify

```php
use Fopost\Laravel\SendTo;

app(SendTo::class)->telegram('Hello from Laravel!');
```

A `PublishResult` comes back with `success` true and an `externalUrl`. It never throws, so check `success` rather than wrapping it in a try/catch.
