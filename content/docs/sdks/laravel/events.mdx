# Laravel Events

The package bridges the library's events onto Laravel's dispatcher, so `PostPublished` and `PostFailed` are ordinary Laravel events you subscribe to normally.

## The events

| Event | Fired when |
|:------|:-----------|
| `Owlstack\Core\Events\PostPublished` | A network accepted the post |
| `Owlstack\Core\Events\PostFailed` | A network rejected it, or the attempt errored |

One per network. Publishing to five networks fires five events.

Both carry the same two properties:

```php
$event->post;                    // the Post
$event->result;                  // the PublishResult
$event->result->platformName;    // 'telegram'
$event->result->externalId;      // '12345'
$event->result->externalUrl;     // URL, or null
$event->result->error;           // message, on failure
$event->result->timestamp;       // DateTimeImmutable
```

## Listening

With a closure:

```php
use Illuminate\Support\Facades\Event;
use Owlstack\Core\Events\PostFailed;
use Owlstack\Core\Events\PostPublished;

Event::listen(PostPublished::class, function (PostPublished $event) {
    Log::info("Published to {$event->result->platformName}", [
        'external_id' => $event->result->externalId,
        'external_url' => $event->result->externalUrl,
    ]);
});

Event::listen(PostFailed::class, function (PostFailed $event) {
    Log::warning("Failed on {$event->result->platformName}: {$event->result->error}");
});
```

Or with a listener class registered the way your Laravel version registers them.

## Writing a delivery row

The usual reason to listen: record what happened once, rather than at every call site.

```php
use Owlstack\Core\Delivery\DeliveryStatus;

class RecordDelivery
{
    public function handle(PostPublished|PostFailed $event): void
    {
        Delivery::create([
            'post_id'      => $event->post->getMeta('post_id'),
            'platform'     => $event->result->platformName,
            'status'       => $event->result->success
                ? DeliveryStatus::Published->value
                : DeliveryStatus::Failed->value,
            'external_id'  => $event->result->externalId,
            'external_url' => $event->result->externalUrl,
            'error'        => $event->result->error,
        ]);
    }
}
```

`Post::$metadata` is never sent to a network and survives into the event, so put your own identifier there. Without it a listener sees content and a network name and has to guess which record produced it.

## Queue slow listeners

Events dispatch inline, so a listener that calls Slack or sends an email slows publishing. Implement `ShouldQueue` on anything that is not a local write.

```php
class NotifyTeam implements ShouldQueue
{
    public function handle(PostFailed $event): void { /* ... */ }
}
```
