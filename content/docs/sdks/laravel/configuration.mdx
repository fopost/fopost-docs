# Laravel Configuration

`php artisan vendor:publish --tag=owlstack-config` writes `config/owlstack.php`. It has two sections: platform credentials, and an optional proxy.

## Platforms

Every network reads its credentials from the environment:

```php
return [
    'platforms' => [
        'telegram' => [
            'api_token' => env('TELEGRAM_BOT_TOKEN', ''),
            'channel_username' => env('TELEGRAM_CHANNEL_USERNAME', ''),
            'parse_mode' => env('TELEGRAM_PARSE_MODE', 'HTML'),
        ],
        'twitter' => [
            'consumer_key' => env('TWITTER_CONSUMER_KEY', ''),
            // ...
        ],
    ],
];
```

**Only networks with credentials are registered.** Leave a network blank and it is simply not available, rather than failing when something tries to publish to it. That is what makes a partially configured `.env` behave sensibly in staging.

## Environment variables

```dotenv
# Telegram
TELEGRAM_BOT_TOKEN=
TELEGRAM_BOT_USERNAME=
TELEGRAM_CHANNEL_USERNAME=@your_channel
TELEGRAM_CHANNEL_SIGNATURE=
TELEGRAM_PARSE_MODE=HTML

# X (Twitter)
TWITTER_CONSUMER_KEY=
TWITTER_CONSUMER_SECRET=
TWITTER_ACCESS_TOKEN=
TWITTER_ACCESS_TOKEN_SECRET=

# Facebook
FACEBOOK_APP_ID=
FACEBOOK_APP_SECRET=
FACEBOOK_PAGE_ACCESS_TOKEN=
FACEBOOK_PAGE_ID=
FACEBOOK_GRAPH_VERSION=v21.0

# LinkedIn
LINKEDIN_ACCESS_TOKEN=
LINKEDIN_PERSON_ID=
LINKEDIN_ORGANIZATION_ID=

# Reddit
REDDIT_CLIENT_ID=
REDDIT_CLIENT_SECRET=
REDDIT_ACCESS_TOKEN=
REDDIT_USERNAME=

# Discord
DISCORD_BOT_TOKEN=
DISCORD_CHANNEL_ID=
DISCORD_WEBHOOK_URL=

# Slack
SLACK_BOT_TOKEN=
SLACK_CHANNEL=#your-channel

# Instagram
INSTAGRAM_ACCESS_TOKEN=
INSTAGRAM_ACCOUNT_ID=

# Pinterest
PINTEREST_ACCESS_TOKEN=
PINTEREST_BOARD_ID=

# WhatsApp
WHATSAPP_ACCESS_TOKEN=
WHATSAPP_PHONE_NUMBER_ID=

# Tumblr
TUMBLR_ACCESS_TOKEN=
TUMBLR_BLOG_IDENTIFIER=your-blog.tumblr.com
```

LinkedIn takes `LINKEDIN_PERSON_ID` for personal posts or `LINKEDIN_ORGANIZATION_ID` for a company page. Discord and Slack take either a bot token with a channel, or a webhook URL.

What each network needs, and how to get it, is on [Configure Credentials](/developers/getting-started/connect-platforms).

## Proxy

For servers that cannot reach a network directly:

```dotenv
OWLSTACK_PROXY_TYPE=7          # 7 is SOCKS5
OWLSTACK_PROXY_HOST=localhost
OWLSTACK_PROXY_PORT=9050
OWLSTACK_PROXY_USERNAME=
OWLSTACK_PROXY_PASSWORD=
```

Applies to every network.

## No API key

There is no `OWLSTACK_API_KEY`. The package publishes with your own platform credentials and never calls our API. An API key is for the [Cloud](/api/authentication), which is a separate product.
