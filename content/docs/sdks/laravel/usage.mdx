# Laravel Usage

Two entry points, doing the same thing: inject `SendTo`, or call the `Fopost` facade.

## Dependency injection

```php
use Fopost\Laravel\SendTo;

class PostController extends Controller
{
    public function publish(SendTo $sendTo)
    {
        $result = $sendTo->telegram('Hello from Laravel!');

        return $result->success
            ? back()->with('status', "Published: {$result->externalUrl}")
            : back()->withErrors($result->error);
    }
}
```

## The facade

```php
use Fopost\Laravel\Facades\Fopost;

Fopost::telegram('Hello from the facade!');
Fopost::twitter('Posting from the facade.');
Fopost::linkedin('And LinkedIn too.');
```

## One method per network

Each takes the message first, then whatever that network needs:

```php
$sendTo->telegram($message, $media, $options);
$sendTo->twitter($message, $media, $options);
$sendTo->x($message, $media, $options);              // alias for twitter
$sendTo->linkedin($message, $media, $options);
$sendTo->discord($message, $media, $options);
$sendTo->instagram($message, $media, $options);
$sendTo->tumblr($message, $media, $options);

$sendTo->facebook($message, $type, $data, $options);
$sendTo->pinterest($message, $data, $options);
$sendTo->reddit($message, $options);
$sendTo->slack($message, $options);
$sendTo->whatsapp($message, $options);
```

Networks that need a target take it in `$options`:

```php
$sendTo->reddit('Post body', [
    'title' => 'Post Title',
    'subreddit' => 'php',
]);

$sendTo->whatsapp('Hello!', ['to' => '+1234567890']);

$sendTo->facebook('Check this out!', 'link', [
    'link' => 'https://example.com',
]);
```

## A Post across networks

For the same content going to several networks, build a `Post`:

```php
use Fopost\Core\Content\Post;

$post = new Post(
    title: 'Release notes',
    body: 'Version 2.0 is out.',
    url: 'https://example.com/releases/v2',
    tags: ['release', 'php'],
);

$result  = $sendTo->publish($post, 'linkedin');  // one network
$results = $sendTo->toAll($post);                // every configured network
```

`toAll()` returns one result per network, keyed by name. Each is independent, so a failure on one does not affect the rest.

## Media

```php
use Fopost\Core\Content\Media;
use Fopost\Core\Content\MediaCollection;

$media = (new MediaCollection())->add(new Media(
    path: storage_path('app/photo.jpg'),
    mimeType: 'image/jpeg',
    altText: 'A sunset over the ocean',
));

$post = new Post(title: 'Sunset', body: 'From the office window.', media: $media);
$sendTo->publish($post, 'telegram');
```

`MediaCollection` is immutable, so assign what `add()` returns.

## Results

Every method returns a `PublishResult`, and none of them throw:

```php
$result->success;       // bool
$result->failed();      // bool
$result->platformName;  // 'telegram'
$result->externalId;    // '12345'
$result->externalUrl;   // URL, when the network returns one
$result->error;         // message, when it failed
```

Branch on `success`. A network being down is a result, not an exception.

## Queue it

Publishing calls a third-party API over the network, which does not belong inside a web request. Put it in a job:

```php
use Illuminate\Contracts\Queue\ShouldQueue;
use Fopost\Laravel\SendTo;

class PublishToSocial implements ShouldQueue
{
    public function __construct(private string $body) {}

    public function handle(SendTo $sendTo): void
    {
        $result = $sendTo->telegram($this->body);

        if ($result->failed()) {
            Log::warning('Publish failed', ['error' => $result->error]);
        }
    }
}

PublishToSocial::dispatch('Hello from the queue!');
```

Laravel's own retry and backoff apply. Retry a rate limit; do not retry an expired token, which will fail identically forever.
