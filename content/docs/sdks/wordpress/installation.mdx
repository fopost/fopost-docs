# WordPress Installation

## Requirements

- WordPress 6.4 or newer
- PHP 8.1 or newer

No OwlStack account is required. The plugin publishes with credentials you hold, through the [PHP library](/developers).

## Install from WordPress.org

1. **Plugins → Add New** in the WordPress admin
2. Search for **Owlstack**
3. **Install Now**, then **Activate**

## Install manually

1. Download the plugin zip, or clone [owlstack-wp](https://github.com/owlstacks/owlstack-wp) into `wp-content/plugins/owlstack`
2. From a source checkout, run `composer install` in the plugin directory. A packaged zip already has its dependencies
3. **Plugins → Add New → Upload Plugin**, upload, activate

## Configure

Go to **Owlstack → Settings** and enter credentials for each network you want. Each network's required keys are listed under [Configure Credentials](/developers/getting-started/connect-platforms).

Only networks with valid credentials appear in the editor, so a half-filled settings page shows fewer options rather than failing at publish time.

Use the connection test on each network. It is the fastest way to find a wrong token.

Then pick which post types show the publishing meta box. Posts only, by default.

## Verify

Open any post edit screen. The **Owlstack** meta box should be in the sidebar with your configured networks listed.

## Connecting to the Cloud instead

If you have an OwlStack Cloud account and want to compose in the dashboard and push into WordPress, that is a different setup. See [Cloud Connect](./cloud-connect).

The two are independent: the plugin can publish out to networks with your own credentials, receive posts from the Cloud, or both.
