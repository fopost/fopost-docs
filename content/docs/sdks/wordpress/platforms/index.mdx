# Platform Configuration

The FoPost WordPress plugin lets you configure each social media platform directly from the WordPress admin. Each platform has its own settings page under **FoPost** in the admin menu.

## Supported Platforms

| Platform | Menu Location |
|:---------|:-------------|
| [Telegram](./platforms/telegram) | FoPost > Telegram |
| [Twitter / X](./platforms/twitter) | FoPost > Twitter / X |
| [Facebook](./platforms/facebook) | FoPost > Facebook |
| [Instagram](./platforms/instagram) | FoPost > Instagram |
| [LinkedIn](./platforms/linkedin) | FoPost > LinkedIn |
| [Discord](./platforms/discord) | FoPost > Discord |
| [Pinterest](./platforms/pinterest) | FoPost > Pinterest |
| [Reddit](./platforms/reddit) | FoPost > Reddit |
| [Slack](./platforms/slack) | FoPost > Slack |
| [Tumblr](./platforms/tumblr) | FoPost > Tumblr |
| [WhatsApp](./platforms/whatsapp) | FoPost > WhatsApp |

## How It Works

1. Navigate to the platform settings page in **FoPost** admin menu
2. Enter your API credentials (tokens, keys, etc.)
3. Click **Save Settings**
4. Use the **Test Connection** button to verify your credentials
5. Send a **Test Message** to confirm end-to-end publishing

<Callout type="info" title="Credentials Security">
All secret fields (API tokens, keys, secrets) are stored encrypted in the WordPress database and displayed as password fields in the admin UI.
</Callout>

## Testing

Every platform settings page includes a built-in testing section with:

- **Connection Test** validates that your API credentials are correct and the platform is reachable
- **Text Message Test** sends a sample text post to verify publishing works end-to-end
- **Image and Media Test**, guidance on testing media publishing via a test WordPress post
- **Video Test**, guidance on testing video publishing

## Using Platforms

Once configured, platforms appear in the **FoPost meta box** on the post edit screen. You can:

- Toggle individual platforms per post
- Set default platforms in **FoPost > Settings**
- Use the `fopost_post_platforms` filter to control platforms programmatically

```php
// Publish to a specific platform using the helper
fopost()->telegram('Hello from WordPress!');
fopost()->twitter('Hello from WordPress!');
fopost()->facebook('Hello from WordPress!');
```
