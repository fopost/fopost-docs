# Meta Box

**Owlstack: Publish to Social Media** appears in the sidebar of the post edit screen, on every post type you have enabled.

## What is in it

- **A checkbox per configured network.** Only networks with valid credentials appear. With none configured, the box links you to settings instead of showing an empty list
- **A publish button per network**, to send to one network on the spot without saving the post
- **An auto-publish toggle**, per post

## Auto-publish

With auto-publish enabled, the post goes to the ticked networks when it is published in WordPress: a draft transitioning to published, or a scheduled post going live.

The per-post toggle overrides the global setting, so a post you would rather not share is one checkbox rather than a settings trip.

## Which post types

Posts only, by default. Add more with the `owlstack_supported_post_types` filter:

```php
add_filter('owlstack_supported_post_types', function ($types) {
    return ['post', 'page', 'product'];
});
```

## Both editors

The box registers in the `side` context, so it appears in the block editor's post settings sidebar and in the classic editor's sidebar column.

## Who sees it

Anyone with the `owlstack_publish` capability, which the plugin grants to administrators on activation. Grant it to editors and they can publish to social without being able to see or change your credentials. See [REST API](./rest-api#capabilities).

## What is not here

There is no per-network caption override in the meta box: WordPress supplies the title, content, URL, and tags, and each network's formatter shapes them. To change what goes out, use the `owlstack_post_data` filter, or the [Cloud composer](/guide/using-owlstack/creating-posts) if you want per-network editing with previews.
