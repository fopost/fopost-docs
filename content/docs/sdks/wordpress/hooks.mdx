# Hooks

Seven hooks, all prefixed `owlstack_`.

## Actions

### `owlstack_before_publish`

Fires before anything is sent.

```php
add_action('owlstack_before_publish', function ($corePost, $platforms, $wpPost) {
    error_log("Publishing '{$wpPost->post_title}' to " . implode(', ', $platforms));
}, 10, 3);
```

| Argument | What |
|:---------|:-----|
| `$corePost` | The `Owlstack\Core\Content\Post` about to be published |
| `$platforms` | Array of network names |
| `$wpPost` | The `WP_Post` it came from |

### `owlstack_after_publish`

Fires once the whole run is done.

```php
add_action('owlstack_after_publish', function ($results, $wpPost) {
    $failed = array_filter($results, fn($r) => $r->failed());
    if ($failed) {
        error_log(count($failed) . ' network(s) failed for post ' . $wpPost->ID);
    }
}, 10, 2);
```

### `owlstack_post_published`

Fires per network, on success.

```php
add_action('owlstack_post_published', function ($result, $wpPost, $platform) {
    update_post_meta($wpPost->ID, "_owlstack_{$platform}_url", $result->externalUrl);
}, 10, 3);
```

### `owlstack_post_failed`

Fires per network, on failure. Same three arguments.

```php
add_action('owlstack_post_failed', function ($result, $wpPost, $platform) {
    error_log("Failed on {$platform}: {$result->error}");
}, 10, 3);
```

Both carry a `PublishResult`: `success`, `platformName`, `externalId`, `externalUrl`, `error`, `timestamp`.

The plugin also bridges the library's own events onto actions of the same names, receiving a `PostPublished` or `PostFailed` event object instead. Read the arguments you are given rather than assuming a shape.

## Filters

### `owlstack_supported_post_types`

Which post types show the meta box. Defaults to `['post']`.

```php
add_filter('owlstack_supported_post_types', function ($types) {
    return ['post', 'page', 'product'];
});
```

### `owlstack_post_data`

The `Post` object, just before publishing. Your last chance to change what goes out.

```php
add_filter('owlstack_post_data', function ($post, $wpPost) {
    return $post;
}, 10, 2);
```

`Post` is readonly, so return a new one rather than mutating the argument.

### `owlstack_publish_options`

Per-network options, before publishing. This is where a required field that WordPress has no concept of gets supplied.

```php
add_filter('owlstack_publish_options', function ($options, $wpPost) {
    $options['reddit']['subreddit'] = 'php';
    return $options;
}, 10, 2);
```

## Argument counts

WordPress passes one argument unless you say otherwise. Every example above sets the fourth `add_action`/`add_filter` argument, and forgetting it is the usual reason a hook "does not fire" when it did.
