# Quick Start (Laravel)

`fopost/fopost-social-laravel` wires the PHP library into Laravel: config from `.env`, a service provider, a facade, and events. It adds no platform logic of its own, so anything about how a network behaves is documented under [Platforms](/developers/platforms/overview).

Supports Laravel 10 through 12.

## 1. Install

```bash
composer require fopost/fopost-social-laravel
php artisan vendor:publish --tag=fopost-config
```

The service provider is auto-discovered.

## 2. Configure

Put credentials in `.env`. Telegram is the fastest to get working:

```dotenv
TELEGRAM_BOT_TOKEN=your-bot-token
TELEGRAM_CHANNEL_USERNAME=@your_channel
TELEGRAM_PARSE_MODE=HTML
```

Only networks with valid credentials are registered. Leave X blank and X simply is not available, rather than failing at publish time. The published config file lists every supported variable.

## 3. Publish

Inject `SendTo`:

```php
use Fopost\Laravel\SendTo;

class PostController extends Controller
{
    public function publish(SendTo $sendTo)
    {
        $result = $sendTo->telegram('Hello from Laravel!');

        return $result->success
            ? back()->with('status', "Published: {$result->externalUrl}")
            : back()->withErrors($result->error);
    }
}
```

Or use the facade:

```php
use Fopost\Laravel\Facades\Fopost;

Fopost::telegram('Hello from the facade!');
Fopost::twitter('Posting from the facade.');
Fopost::linkedin('And LinkedIn too.');
```

## 4. Per-network arguments

Each method takes the options that network needs:

```php
$sendTo->reddit('Post body', [
    'title' => 'Post Title',
    'subreddit' => 'php',
]);

$sendTo->instagram('Caption text', [
    'path' => '/path/to/image.jpg',
    'mime_type' => 'image/jpeg',
]);

$sendTo->whatsapp('Hello!', ['to' => '+1234567890']);

$sendTo->facebook('Check this out!', 'link', [
    'link' => 'https://example.com',
]);
```

`$sendTo->x()` is an alias for `twitter()`.

## 5. Read the result

Every method returns a `PublishResult`, and none of them throw:

```php
$result = $sendTo->telegram('Hello!');

$result->success;       // bool
$result->failed();      // bool
$result->platformName;  // 'telegram'
$result->externalId;    // '12345'
$result->externalUrl;   // URL, when the network returns one
$result->error;         // message, when it failed
```

Check `success` rather than wrapping the call in a try/catch. A network being down is a result, not an exception.

## Queue it

Publishing calls a third-party API over the network, which is not something to do inside a web request. Put it in a job:

```php
class PublishToSocial implements ShouldQueue
{
    public function __construct(private string $body) {}

    public function handle(SendTo $sendTo): void
    {
        $result = $sendTo->telegram($this->body);

        if ($result->failed()) {
            Log::warning('Publish failed', ['error' => $result->error]);
        }
    }
}
```
