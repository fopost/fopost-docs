# Quick Start

Publishing to Telegram, end to end. Telegram first because a bot token takes about a minute to get from [@BotFather](https://t.me/BotFather), with no app review in the way.

## 1. Install

```bash
composer require fopost/fopost-social-core
```

## 2. Publish

```php
<?php

require __DIR__ . '/vendor/autoload.php';

use Fopost\Core\Config\PlatformCredentials;
use Fopost\Core\Content\Post;
use Fopost\Core\Http\HttpClient;
use Fopost\Core\Platforms\PlatformRegistry;
use Fopost\Core\Platforms\Telegram\TelegramFormatter;
use Fopost\Core\Platforms\Telegram\TelegramPlatform;
use Fopost\Core\Publishing\Publisher;

// Credentials you obtained from the network itself
$credentials = new PlatformCredentials('telegram', [
    'api_token' => getenv('TELEGRAM_BOT_TOKEN'),
    'channel_username' => '@your-channel',
]);

// A platform is credentials + an HTTP client + a formatter
$platform = new TelegramPlatform($credentials, new HttpClient(), new TelegramFormatter());

$registry = new PlatformRegistry();
$registry->register($platform);

$publisher = new Publisher($registry);

$post = new Post(
    title: 'Hello World',
    body: 'My first post via Fopost.',
    url: 'https://example.com/hello-world',
    tags: ['opensource', 'php'],
);

$result = $publisher->publish($post, 'telegram');

if ($result->success) {
    echo "Published: {$result->externalUrl}\n";
} else {
    echo "Failed: {$result->error}\n";
}
```

`publish()` never throws. A bad token, an unreachable network, or content over the limit all come back as a `PublishResult` with `success` false and an `error` you can log.

## 3. Add media

```php
use Fopost\Core\Content\Media;
use Fopost\Core\Content\MediaCollection;

$media = (new MediaCollection())
    ->add(new Media(
        path: '/path/to/photo.jpg',
        mimeType: 'image/jpeg',
        altText: 'A sunset over the ocean',
    ));

$post = new Post(
    title: 'Sunset',
    body: 'Taken from the office window.',
    media: $media,
    tags: ['photography'],
);
```

`MediaCollection` is immutable: `add()` returns a new collection rather than mutating the old one, so assign the result.

## 4. Publish to several networks

Register each platform, then loop:

```php
$registry->register($telegramPlatform);
$registry->register($twitterPlatform);
$registry->register($discordPlatform);

foreach ($registry->names() as $name) {
    $result = $publisher->publish($post, $name);
    echo $result->success
        ? "{$name}: {$result->externalUrl}\n"
        : "{$name}: {$result->error}\n";
}
```

Each network is published independently, so one failure does not stop the others.

## 5. Per-network options

The third argument to `publish()` is passed through to that network:

```php
$publisher->publish($post, 'telegram', [
    'chat_id' => '@another-channel',
    'disable_notification' => true,
]);

$publisher->publish($post, 'reddit', [
    'subreddit' => 'php',
    'kind' => 'self',
]);
```

Every option is on the [platform pages](/developers/platforms/overview).
