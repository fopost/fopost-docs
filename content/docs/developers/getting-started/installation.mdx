# Installation

## Requirements

| Requirement | Version |
|:------------|:--------|
| PHP | 8.1 or higher |
| ext-curl | any |
| ext-json | any |

No other extensions and no Composer dependencies.

## Standalone PHP

```bash
composer require owlstack/owlstack-core
```

That is the whole library. Nothing to configure at install time, because credentials are passed to the platform objects you construct. See the [quick start](./quick-start).

## Laravel

```bash
composer require owlstack/owlstack-laravel
```

The service provider is auto-discovered. Publish the config:

```bash
php artisan vendor:publish --tag=owlstack-config
```

Then put your platform credentials in `.env`. The Laravel package pulls in `owlstack/owlstack-core` for you. See the [Laravel quick start](./quick-start-laravel).

## WordPress

Install the plugin, then set your credentials in **WP Admin → OwlStack → Settings**. See the [WordPress quick start](./quick-start-wordpress).

If you installed from a source checkout rather than a packaged zip, run Composer inside the plugin directory first:

```bash
cd wp-content/plugins/owlstack
composer install
```

## What you need next

Credentials for each network you want to publish to, obtained from that network. The library never brokers them.

Telegram, Discord, and Slack take minutes. X, Reddit, and Tumblr are self-service registrations. Facebook, Instagram, LinkedIn, Pinterest, and WhatsApp need an app review before production, which takes as long as it takes. Plan around that rather than discovering it on launch day.

[Configure credentials](./connect-platforms) walks through the shape of each.

## Looking for the Cloud?

If you wanted scheduling, analytics, a dashboard, and the rest of the networks, none of the above applies. That is the [Cloud API](/api/overview) and its [TypeScript](/sdks/typescript) and [Python](/sdks/python) clients.
