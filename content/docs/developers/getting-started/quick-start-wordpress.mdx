# Quick Start (WordPress)

The FoPost plugin wraps the PHP library for WordPress: an admin settings page, a meta box in the editor, auto-publish on publish, delivery logs, and hooks. Credentials are yours and are entered in WordPress, not in a cloud dashboard.

Requires PHP 8.1 or newer and WordPress 6.4 or newer.

## 1. Install

Upload the plugin zip, or clone into `wp-content/plugins/fopost`. From a source checkout, run Composer in the plugin directory first:

```bash
cd wp-content/plugins/fopost
composer install
```

Activate it from **WP Admin → Plugins**.

## 2. Configure

Go to **Fopost → Settings** and enter credentials for the networks you want. Each network's required keys are listed under [Configure Credentials](./connect-platforms); the settings page has a connection test per network, which is the fastest way to catch a wrong token.

Only networks with valid credentials appear in the editor.

## 3. Publish from the editor

Editing a post shows an **Fopost** meta box. Tick the networks and publish. With auto-publish enabled, hitting Publish sends the post out at the same time.

By default the meta box appears on posts only. Add other post types with the `fopost_supported_post_types` filter.

## 4. Publish from code

The `fopost()` helper is available anywhere in a theme or plugin:

```php
fopost()->telegram('Hello from WordPress!');
fopost()->twitter('Hello from WordPress!');
fopost()->x('Hello from WordPress!');            // alias

fopost()->facebook('Check this out!', 'link', [
    'link' => 'https://example.com',
]);
```

Build a `Post` for anything richer:

```php
use Fopost\Core\Content\Post;

$post = new Post(
    title: 'My Post',
    body: 'Hello world!',
    url: 'https://example.com/my-post',
    tags: ['wordpress'],
);

fopost()->publish($post, 'linkedin');  // one network
fopost()->toAll($post);                // every configured network
```

## 5. Hooks

```php
add_action('fopost_post_published', function ($event) {
    error_log("Published to {$event->result->platformName}");
});

add_action('fopost_post_failed', function ($event) {
    error_log("Failed: {$event->result->error}");
});
```

| Hook | Kind | Receives |
|:-----|:-----|:---------|
| `fopost_before_publish` | action | The `WP_Post` and the target network names |
| `fopost_after_publish` | action | The `WP_Post` and the results |
| `fopost_post_published` | action | A `PostPublished` event |
| `fopost_post_failed` | action | A `PostFailed` event |
| `fopost_supported_post_types` | filter | The post types showing the meta box |
| `fopost_post_data` | filter | The `Post` before publishing |
| `fopost_publish_options` | filter | Per-network options before publishing |

## Delivery logs

Every attempt is recorded with its status, the error if it failed, and a link to the published item. That is where to look when a post did not appear, rather than in the PHP error log.

## Notes

The plugin uses the WordPress HTTP API rather than cURL directly, so it honours your site's HTTP configuration. OAuth tokens are stored encrypted in `wp_options`.
