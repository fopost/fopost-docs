# What the library is

`fopost/fopost-social-core` gives you one PHP API for eleven social networks. You build a `Post`, register the platforms you have credentials for, and publish. The library handles each network's API, its character limit, its markup dialect, and its media rules.

```php
use Fopost\Core\Content\Post;
use Fopost\Core\Publishing\Publisher;

$publisher = new Publisher($registry);

$post = new Post(
    title: 'Hello World',
    body: 'My first post via Fopost.',
    url: 'https://example.com/hello-world',
    tags: ['opensource', 'php'],
);

$result = $publisher->publish($post, 'telegram');
```

## What you get

- **Eleven networks, one API.** Telegram, X, Facebook, LinkedIn, Discord, Instagram, Pinterest, Reddit, Slack, Tumblr, and WhatsApp
- **Zero dependencies.** PHP 8.1 or newer, `ext-curl`, `ext-json`. Nothing else, so it drops into any codebase
- **Contract-driven.** HTTP, storage, events, and auth each sit behind an interface you can replace
- **Immutable value objects.** `Post`, `Media`, `MediaCollection`, and `AccessToken` are all readonly
- **Publishing that does not throw.** `Publisher::publish()` always returns a `PublishResult`, so one failed network cannot take down your request
- **Per-platform formatting.** Each network has its own formatter honouring its limits, markup, and media constraints

## What you provide

Credentials, per network, obtained from that network. A Telegram bot token from BotFather, an X app from the developer portal, a Discord webhook URL. The library never brokers this for you, which is exactly the trade: you own the apps, the rate limits, and the review process.

Some networks hand you credentials in minutes. Others need an app review first. [Which is which](/developers/platforms/overview#getting-access) is worth reading before you plan a launch around one.

## What it does not do

No scheduling, no queue, no analytics, no dashboard, no retries across process restarts, no team. It is a publishing engine, not a product. Those live in the [Cloud API](/api/overview), which is the other way to use FoPost.

If you want the engine but not the wiring, the [Laravel](/sdks/laravel/installation) and [WordPress](/sdks/wordpress/installation) packages add queues, config, and an admin UI on top of it.

## Networks

| Network | Highlights |
|:--------|:-----------|
| Telegram | Channels, groups, media groups, inline keyboards, locations, pinning |
| X (Twitter) | Replies, quote posts, polls, t.co-aware character budget |
| Facebook | Page publishing, privacy, native scheduling |
| LinkedIn | Personal profiles and company pages, visibility control |
| Discord | Bot or webhook, rich embeds, threads |
| Instagram | Feed images, Reels, Stories, carousels |
| Pinterest | Boards and sections, alt text, dominant colour |
| Reddit | Self and link posts, subreddit, flair, NSFW and spoiler flags |
| Slack | Bot or webhook, Block Kit, threads |
| Tumblr | Text, image, video, link, and audio posts, drafts and queue |
| WhatsApp | Text, media, and template messages via the Business API |
