# PHP Library

`fopost/fopost-social-core` is a framework-agnostic PHP library for publishing to social networks. It talks to the platform APIs directly, using credentials you hold, and it needs nothing from us at runtime: no account, no API key, no network hop through our servers.

```bash
composer require fopost/fopost-social-core
```

Pure PHP 8.1 or newer. The only requirements are `ext-curl` and `ext-json`. MIT licensed, on [GitHub](https://github.com/fopost/fopost-social-core).

## This is not the Cloud API

Two different things share a name, and picking the wrong one wastes an afternoon.

| | PHP library | [Cloud API](/api/overview) |
|:--|:--|:--|
| Where publishing runs | Your server | Ours |
| Credentials | Yours, per platform | Connected once via OAuth in the dashboard |
| Networks | 11 | Every network FoPost supports |
| Scheduling, analytics, team | You build it | Included |
| Account needed | No | Yes |
| Cost | Free, MIT | A plan |

Use the library when you want to own the whole pipeline, are already in PHP, and are happy registering apps with each network yourself. Use the Cloud API when you want scheduling, retries, analytics, a dashboard, and the other networks without building any of it.

They are separate products. The library does not call the Cloud API, and a Cloud API key does nothing here.

## Framework wrappers

The library is the engine. Two packages wire it into a framework without duplicating any of its logic:

- [Laravel](/sdks/laravel/installation), a service provider, facade, config, and events
- [WordPress](/sdks/wordpress/installation), a plugin with an admin panel, meta boxes, and delivery logs
