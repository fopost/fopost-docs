# WhatsApp

WhatsApp is a messaging API, not a broadcast network. Every send goes to a specific number, and unsolicited messages need a pre-approved template.

## Credentials

```php
$credentials = new PlatformCredentials('whatsapp', [
    'access_token' => '...',
    'phone_number_id' => '...',
]);
```

## Getting access

Meta Business verification, then the WhatsApp Business Platform in the [Meta developer portal](https://developers.facebook.com/docs/whatsapp). This is the longest onboarding of the eleven: verification, a registered number, and template approval each take their own time.

## Publish

```php
$result = $publisher->publish($post, 'whatsapp');
```

## Options

| Option | Type | Description |
|:-------|:-----|:------------|
| `to` | `string` | **Required.** Recipient in E.164 format |
| `message_type` | `string` | `text`, `image`, `video`, `document`, or `template` |
| `template_name` | `string` | Approved template name |
| `template_lang` | `string` | Template language, for example `en_US` |
| `preview_url` | `bool` | Render a link preview |

```php
$publisher->publish($post, 'whatsapp', [
    'to' => '+1234567890',
    'message_type' => 'template',
    'template_name' => 'hello_world',
    'template_lang' => 'en_US',
]);
```

## Constraints

| Constraint | Value |
|:-----------|:------|
| Max text length | 4,096 characters |
| Markup | Plain text |

Read them at runtime with `$platform->constraints()` rather than hardcoding, since networks change them.

## Templates and the 24-hour window

Free-form messages are only allowed inside a 24-hour window opened by the recipient messaging you first. Outside it, you may send only a template Meta has approved in advance.

That is a policy constraint, not an API quirk, and the penalty for working around it is losing the number. Design around templates from the start rather than discovering the window in production.
