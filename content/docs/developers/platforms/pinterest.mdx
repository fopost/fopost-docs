# Pinterest

Pinterest pins to a board. Production API access needs approval.

## Credentials

```php
$credentials = new PlatformCredentials('pinterest', [
    'access_token' => '...',
    'board_id' => '...',
]);
```

## Getting access

Register an app in the [Pinterest developer portal](https://developers.pinterest.com/) with a Business account. Apps start in trial mode against your own account; publishing for others needs production access, which is reviewed.

## Publish

```php
$result = $publisher->publish($post, 'pinterest');
```

## Options

| Option | Type | Description |
|:-------|:-----|:------------|
| `board_section_id` | `string` | Pin into a section of the board |
| `image_url` | `string` | Publicly reachable image URL |
| `alt_text` | `string` | Accessibility description |
| `dominant_color` | `string` | Hex colour hint, for example `#FF5733` |

```php
$publisher->publish($post, 'pinterest', [
    'image_url' => 'https://example.com/pin.jpg',
    'alt_text' => 'A flat-lay of the product on a desk',
]);
```

## Constraints

| Constraint | Value |
|:-----------|:------|
| Max description length | 800 characters |
| Markup | Plain text |

Read them at runtime with `$platform->constraints()` rather than hardcoding, since networks change them.

## Pins need an image

A pin without an image is not a pin. Set `image_url` to something publicly reachable, and set `alt_text` while you are there: Pinterest is a search engine, and the description is how a pin gets found.
