# Tumblr

Tumblr posts to one blog, identified by its hostname, and supports drafts and a queue.

## Credentials

```php
$credentials = new PlatformCredentials('tumblr', [
    'access_token' => '...',
    'blog_identifier' => 'myblog.tumblr.com',
]);
```

## Getting access

Register an app at [tumblr.com/oauth/apps](https://www.tumblr.com/oauth/apps). Self-service, no review.

## Publish

```php
$result = $publisher->publish($post, 'tumblr');
```

## Options

| Option | Type | Description |
|:-------|:-----|:------------|
| `post_type` | `string` | `text`, `image`, `video`, `link`, or `audio` |
| `state` | `string` | `published`, `draft`, `queue`, or `private` |
| `slug` | `string` | URL slug for the post |

```php
$publisher->publish($post, 'tumblr', [
    'post_type' => 'text',
    'state' => 'published',
    'slug' => 'my-post-slug',
]);
```

## Constraints

| Constraint | Value |
|:-----------|:------|
| Max text length | 4,096 characters |
| Markup | Content blocks |

Read them at runtime with `$platform->constraints()` rather than hardcoding, since networks change them.

## Drafts and the queue

`state` is worth knowing about. `draft` creates the post without publishing it, which is a good way to test a formatter against a real blog without posting anything. `queue` hands it to Tumblr's own queue, which spaces posts out on a schedule you set in the blog's settings.
