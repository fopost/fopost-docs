# Slack

Slack takes either a bot token with a channel, or an incoming webhook URL.

## Credentials

```php
// Bot
$credentials = new PlatformCredentials('slack', [
    'bot_token' => 'xoxb-...',
    'channel' => '#general',
]);

// Or webhook
$credentials = new PlatformCredentials('slack', [
    'webhook_url' => 'https://hooks.slack.com/services/...',
]);
```

## Getting access

Create an app at [api.slack.com/apps](https://api.slack.com/apps). For a bot, add the `chat:write` scope and install it to the workspace. For a webhook, enable Incoming Webhooks and pick a channel.

## Publish

```php
$result = $publisher->publish($post, 'slack');
```

## Options

| Option | Type | Description |
|:-------|:-----|:------------|
| `blocks` | `bool` | Send as Block Kit rather than plain text |
| `thread_ts` | `string` | Reply inside a thread |
| `unfurl_links` | `bool` | Expand link previews |

```php
$publisher->publish($post, 'slack', [
    'blocks' => true,
    'unfurl_links' => true,
]);
```

## Constraints

| Constraint | Value |
|:-----------|:------|
| Max text length | 40,000 characters |
| Markup | mrkdwn, or Block Kit |

Read them at runtime with `$platform->constraints()` rather than hardcoding, since networks change them.

## Webhook or bot

A webhook is pinned to one channel and cannot read anything, which makes it the safer default for notifications. A bot can post anywhere it is invited and reply in threads.

With `blocks: true` the formatter emits Block Kit, which renders headings, dividers, and links properly. Without it you get mrkdwn, which is fine for one line.
