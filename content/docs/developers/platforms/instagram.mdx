# Instagram

Instagram publishes through the Meta Graph API and requires a Business or Creator account linked to a Facebook Page.

## Credentials

```php
$credentials = new PlatformCredentials('instagram', [
    'access_token' => '...',
    'instagram_account_id' => '...',
]);
```

## Getting access

Convert the account to Business or Creator, link it to a Facebook Page, then use the same Meta app as Facebook. Production publishing needs `instagram_content_publish` through [App Review](https://developers.facebook.com/docs/app-review).

## Publish

```php
$result = $publisher->publish($post, 'instagram');
```

## Options

| Option | Type | Description |
|:-------|:-----|:------------|
| `media_type` | `string` | `IMAGE`, `REELS`, or `STORIES` |
| `image_url` | `string` | Publicly reachable URL of the image |
| `carousel` | `array` | Several items, each with an `image_url` |
| `location_id` | `string` | Tag a location |
| `alt_text` | `string` | Accessibility description |

```php
$publisher->publish($post, 'instagram', [
    'media_type' => 'IMAGE',
    'image_url' => 'https://example.com/photo.jpg',
    'alt_text' => 'A storefront with the lights coming on',
]);

// Carousel
$publisher->publish($post, 'instagram', [
    'carousel' => [
        ['image_url' => 'https://example.com/1.jpg'],
        ['image_url' => 'https://example.com/2.jpg'],
    ],
]);
```

## Constraints

| Constraint | Value |
|:-----------|:------|
| Max caption length | 2,200 characters |
| Carousel items | 10 |
| Markup | Plain text |

Read them at runtime with `$platform->constraints()` rather than hardcoding, since networks change them.

## Media must be hosted

Instagram will not accept an upload from you. The image or video has to already sit at a publicly reachable URL that Meta's servers can fetch, so a local path or a signed URL that expires in sixty seconds will not work.

Host the file somewhere durable first, then pass the URL. This is the single most common reason an Instagram publish fails.
