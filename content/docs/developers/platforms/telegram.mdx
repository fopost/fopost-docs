# Telegram

Telegram is the fastest network to get working: a bot token takes about a minute and there is no app review.

## Credentials

```php
$credentials = new PlatformCredentials('telegram', [
    'api_token' => 'your-bot-token',
    'channel_username' => '@your-channel',
]);

$platform = new TelegramPlatform($credentials, new HttpClient(), new TelegramFormatter());
```

## Getting access

1. Open Telegram and message [@BotFather](https://t.me/BotFather)
2. Send `/newbot` and follow the prompts
3. Copy the token
4. Add the bot as an **admin** to your channel or group, or it cannot post

## Publish

```php
$result = $publisher->publish($post, 'telegram');
```

## Options

| Option | Type | Description |
|:-------|:-----|:------------|
| `chat_id` | `string` | Override the target chat or channel |
| `parse_mode` | `string` | `HTML` or `Markdown` |
| `disable_notification` | `bool` | Send silently |
| `inline_keyboard` | `array` | Buttons under the message |

```php
$publisher->publish($post, 'telegram', [
    'chat_id' => '@specific-channel',
    'parse_mode' => 'HTML',
    'disable_notification' => true,
    'inline_keyboard' => [
        [['text' => 'Visit Site', 'url' => 'https://example.com']],
    ],
]);
```

## Constraints

| Constraint | Value |
|:-----------|:------|
| Max text length | 4,096 characters |
| Max media per group | 10 |
| Markup | HTML, or Markdown via `parse_mode` |

Read them at runtime with `$platform->constraints()` rather than hardcoding, since networks change them.

## Beyond posting

The Telegram platform exposes methods the shared interface has no concept of:

```php
$platform->sendLocation($chatId, 40.7128, -74.0060);
$platform->sendVenue($chatId, 40.7128, -74.0060, 'NYC Office', '123 Main St');
$platform->sendContact($chatId, '+1234567890', 'John');
$platform->pinMessage($chatId, $messageId);
```

Call them on the platform directly rather than through the `Publisher`, which means they throw on failure rather than returning a result.
