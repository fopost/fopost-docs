# LinkedIn

LinkedIn posts as a person or as an organisation, decided by which id you supply.

## Credentials

```php
// Personal profile
$credentials = new PlatformCredentials('linkedin', [
    'access_token' => '...',
    'person_id' => 'abc123',
]);

// Or a company page
$credentials = new PlatformCredentials('linkedin', [
    'access_token' => '...',
    'organization_id' => 'org456',
]);
```

## Getting access

Create an app in the [LinkedIn developer portal](https://learn.microsoft.com/en-us/linkedin/marketing/). Posting to a company page needs Community Management API access, which is an application with a real review behind it. Budget time for it.

## Publish

```php
$result = $publisher->publish($post, 'linkedin');
```

## Options

| Option | Type | Description |
|:-------|:-----|:------------|
| `visibility` | `string` | `PUBLIC` or `CONNECTIONS` |

```php
$publisher->publish($post, 'linkedin', [
    'visibility' => 'PUBLIC',
]);
```

## Constraints

| Constraint | Value |
|:-----------|:------|
| Max text length | 3,000 characters |
| Markup | Plain text |

Read them at runtime with `$platform->constraints()` rather than hardcoding, since networks change them.

## Person or organisation

Supply `person_id` and the post is authored by that person; supply `organization_id` and it is authored by the page. Supplying both is ambiguous, so pick one per credential set. To post to both, register two platform instances with different names.
