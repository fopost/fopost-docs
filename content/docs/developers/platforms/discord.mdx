# Discord

Discord takes either a bot token or a webhook URL. A webhook is faster to set up; a bot can do more.

## Credentials

```php
// Bot
$credentials = new PlatformCredentials('discord', [
    'bot_token' => '...',
    'channel_id' => '...',
]);

// Or webhook
$credentials = new PlatformCredentials('discord', [
    'webhook_url' => 'https://discord.com/api/webhooks/...',
]);
```

## Getting access

For a webhook: server settings, Integrations, New Webhook, copy the URL. That is the whole process, and it needs no app.

For a bot: create an application in the [Discord developer portal](https://discord.com/developers), add a bot, invite it to your server with permission to send messages, and copy the token and the channel id.

## Publish

```php
$result = $publisher->publish($post, 'discord');
```

## Options

| Option | Type | Description |
|:-------|:-----|:------------|
| `embed` | `bool` | Send as a rich embed rather than plain text |
| `color` | `int` | Embed colour, for example `0x5865F2` |
| `thread_id` | `string` | Post into a thread |
| `tts` | `bool` | Text to speech |

```php
$publisher->publish($post, 'discord', [
    'embed' => true,
    'color' => 0x5865F2,
]);
```

## Constraints

| Constraint | Value |
|:-----------|:------|
| Max text length | 2,000 characters |
| Markup | Markdown |

Read them at runtime with `$platform->constraints()` rather than hardcoding, since networks change them.

## Webhook or bot

A webhook posts under the webhook's own name and avatar, cannot read anything, and is revoked by deleting it. That containment is usually a feature.

A bot posts under its own identity, can be given permissions per channel, and can act beyond posting. Use one when a webhook is genuinely not enough.
