# Platforms Overview

The library ships eleven platform implementations. Each is a class you construct with credentials, an HTTP client, and a formatter, then register:

```php
$registry->register(new TelegramPlatform($credentials, $httpClient, new TelegramFormatter()));
$publisher->publish($post, 'telegram');
```

## The eleven

| Network | Name | Highlights |
|:--------|:-----|:-----------|
| [Telegram](./telegram) | `telegram` | Channels, groups, media groups, inline keyboards, locations, pinning |
| [X (Twitter)](./twitter) | `twitter` | Replies, quote posts, polls |
| [Facebook](./facebook) | `facebook` | Page publishing, privacy, native scheduling |
| [LinkedIn](./linkedin) | `linkedin` | Personal profiles and company pages |
| [Discord](./discord) | `discord` | Bot or webhook, rich embeds, threads |
| [Instagram](./instagram) | `instagram` | Feed images, Reels, Stories, carousels |
| [Pinterest](./pinterest) | `pinterest` | Boards and sections, alt text |
| [Reddit](./reddit) | `reddit` | Self and link posts, flair, NSFW and spoiler flags |
| [Slack](./slack) | `slack` | Bot or webhook, Block Kit, threads |
| [Tumblr](./tumblr) | `tumblr` | Text, image, video, link, audio, drafts and queue |
| [WhatsApp](./whatsapp) | `whatsapp` | Text, media, and template messages |

## Getting access

How long a network takes to enable varies from a minute to a month. Worth knowing before you plan around one.

**Minutes, no review.** Telegram via [@BotFather](https://t.me/BotFather). Discord and Slack via a webhook URL or a bot token created in your own server or workspace.

**Self-service registration.** X at [developer.x.com](https://developer.x.com), Reddit at [reddit.com/prefs/apps](https://www.reddit.com/prefs/apps), Tumblr at [tumblr.com/oauth/apps](https://www.tumblr.com/oauth/apps).

**App review before production.**

| Network | What is reviewed | Where |
|:--------|:-----------------|:------|
| Facebook | `pages_manage_posts`, `pages_read_engagement` | [Meta App Review](https://developers.facebook.com/docs/app-review) |
| Instagram | `instagram_content_publish` | Meta App Review, same portal |
| LinkedIn | Community Management API access | [LinkedIn developer portal](https://learn.microsoft.com/en-us/linkedin/marketing/) |
| Pinterest | Production API access | [Pinterest developer portal](https://developers.pinterest.com/) |
| WhatsApp | Business verification, plus the Business Platform | [Meta for Developers](https://developers.facebook.com/docs/whatsapp) |

Facebook, Instagram, and WhatsApp share one portal. Apply for all three in a single cycle rather than three.

## Character limits

| Network | Limit |
|:--------|:------|
| X | 280 |
| Pinterest | 800 |
| Discord | 2,000 |
| Instagram | 2,200 |
| LinkedIn | 3,000 |
| Telegram, Tumblr, WhatsApp | 4,096 |
| Reddit, Slack | 40,000 |
| Facebook | 63,206 |

Formatters enforce these. Read the live value with `$formatter->maxLength()` or `$platform->constraints()` rather than copying a number from a table.

## Markup

| Network | Markup |
|:--------|:-------|
| Telegram | HTML, or Markdown |
| Discord, Reddit | Markdown |
| Slack | mrkdwn, or Block Kit |
| Tumblr | Content blocks |
| X, Facebook, LinkedIn, Instagram, Pinterest, WhatsApp | Plain text |

## Not here?

The library covers eleven. The [Cloud API](/api/overview) covers considerably more, including TikTok, YouTube, Bluesky, Mastodon, Threads, and the rest, because it maintains those integrations rather than asking you to.

To add one to the library yourself, [Custom Platforms](/developers/extending/custom-platforms) is one class and one registry line.
