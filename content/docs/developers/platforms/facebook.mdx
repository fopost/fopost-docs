# Facebook

Facebook publishes to Pages, not personal profiles. It needs an app review before production.

## Credentials

```php
$credentials = new PlatformCredentials('facebook', [
    'app_id' => '...',
    'app_secret' => '...',
    'page_access_token' => '...',
    'page_id' => '...',
]);
```

## Getting access

Create an app in the [Meta developer portal](https://developers.facebook.com), add the Pages product, and generate a Page access token for the Page you administer. Publishing in production needs `pages_manage_posts` and `pages_read_engagement` through [App Review](https://developers.facebook.com/docs/app-review). Facebook, Instagram, and WhatsApp share that portal, so apply for all of them in one cycle.

## Publish

```php
$result = $publisher->publish($post, 'facebook');
```

## Options

| Option | Type | Description |
|:-------|:-----|:------------|
| `privacy` | `array` | Audience, for example `['value' => 'EVERYONE']` |
| `scheduled_publish_time` | `int` | Unix timestamp for native scheduling |

```php
$publisher->publish($post, 'facebook', [
    'privacy' => ['value' => 'EVERYONE'],
    'scheduled_publish_time' => time() + 3600,
]);
```

## Constraints

| Constraint | Value |
|:-----------|:------|
| Max text length | 63,206 characters |
| Markup | Plain text |

Read them at runtime with `$platform->constraints()` rather than hardcoding, since networks change them.

## Scheduling

`scheduled_publish_time` hands the post to Facebook to publish later, so it lands even if your server is down. Facebook enforces its own minimum and maximum lead times and rejects anything outside them.
