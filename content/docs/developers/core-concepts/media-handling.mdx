# Media Handling

## Media

One attachment: an image, video, audio file, or document.

```php
use Fopost\Core\Content\Media;

$image = new Media(
    path: '/path/to/photo.jpg',
    mimeType: 'image/jpeg',
    altText: 'A sunset over the ocean',
    width: 1920,
    height: 1080,
    fileSize: 245_000,
);

$image->isImage();     // true
$image->isVideo();     // false
$image->isAudio();     // false
$image->isDocument();  // false
```

Only `path` and `mimeType` are required. Fill in `width`, `height`, and `fileSize` when you know them: they let a platform reject a file that would fail the network's own validation, before the upload rather than after.

`altText` is worth setting. It is what screen readers announce, and several networks surface it.

## MediaCollection

Typed and immutable. `add()` returns a **new** collection, so assign the result:

```php
use Fopost\Core\Content\MediaCollection;

$collection = new MediaCollection();
$collection = $collection->add($image1);
$collection = $collection->add($image2);
$collection = $collection->add($video);

$collection->count();    // 3
$collection->first();    // $image1
$collection->images();   // MediaCollection of the images
$collection->videos();   // MediaCollection of the videos
$collection->isEmpty();  // false
$collection->all();      // Media[]

foreach ($collection as $media) {
    echo $media->path;
}
```

Forgetting to reassign is the one mistake this design invites. `$collection->add($image)` on its own does nothing.

## Attaching to a post

```php
$post = new Post(
    title: 'Sunset',
    body: 'Taken from the office window.',
    media: $collection,
);
```

## Per-network limits

Each platform declares its own constraints, readable through `constraints()`:

```php
$platform->constraints();
// [
//   'max_text_length' => 280,
//   'max_media_count' => 4,
//   'supported_media_types' => ['image/jpeg', 'image/png', 'image/gif'],
//   'max_media_size' => 5 * 1024 * 1024,
// ]
```

Exceeding them raises a `MediaValidationException` inside the platform, which the `Publisher` catches and returns as a failed `PublishResult`. See [Error Handling](./error-handling).

## Hosted media

Some networks will not accept an upload from you at all and require a publicly reachable URL. Instagram is the clearest case: the image must already be hosted somewhere it can fetch. For those, pass the URL through the per-network options rather than a local path:

```php
$publisher->publish($post, 'instagram', [
    'media_type' => 'IMAGE',
    'image_url' => 'https://example.com/photo.jpg',
]);
```

Each [platform page](/developers/platforms/overview) says which of the two it wants.
