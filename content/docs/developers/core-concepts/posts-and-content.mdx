# Posts & Content

Content is platform-agnostic and immutable. You build a `Post` once, and each network's formatter decides what to do with it.

## Post

Every property is readonly, set through the constructor:

```php
use Fopost\Core\Content\Post;

$post = new Post(
    title: 'My Article Title',
    body: 'The full article content goes here...',
    url: 'https://example.com/my-article',
    excerpt: 'A short summary',
    media: $mediaCollection,
    tags: ['php', 'social-media', 'automation'],
    metadata: ['wp_post_id' => 42],
);
```

| Parameter | Type | Default | Description |
|:----------|:-----|:--------|:------------|
| `title` | `string` | required | Post title |
| `body` | `string` | required | Post body |
| `url` | `?string` | `null` | Canonical URL of the original |
| `excerpt` | `?string` | `null` | Short summary, used where space is tight |
| `media` | `?MediaCollection` | `null` | Attachments |
| `tags` | `array` | `[]` | Tags, turned into hashtags per network |
| `metadata` | `array` | `[]` | Arbitrary data of your own |

## Helpers

```php
$post->hasMedia();                     // bool
$post->hasUrl();                       // bool
$post->getMeta('wp_post_id');          // 42
$post->getMeta('missing', 'default');  // 'default'
```

`metadata` is never sent to a network. It is there so you can correlate a `PublishResult` back to your own record, which is what you want when writing delivery status to a database.

## How each field is used

Networks differ, and the formatter for each decides. Broadly:

- **`title`** leads on networks that have a title concept, such as Reddit and Tumblr. On X it usually does not appear at all
- **`body`** is the content, truncated at the network's limit on a word boundary
- **`excerpt`** is preferred over `body` where space is tight
- **`url`** is appended as a "read more" link where that reads naturally, and is counted against the character budget correctly. X wraps every URL to a fixed width, and its formatter accounts for that
- **`tags`** become hashtags in the network's preferred style and position, within whatever budget is left

You do not choose the markup dialect. Telegram gets HTML, Discord and Reddit get Markdown, Slack gets mrkdwn, and the formatter converts.

## Canonical links

`CanonicalLink` is the piece that appends a link without blowing the limit:

```php
use Fopost\Core\Content\CanonicalLink;

$link = new CanonicalLink("\n\nRead more: {url}");
$text = $link->inject($content, 'https://example.com', maxLength: 280);
```

It trims the content, not the link, so the URL always survives.

## Immutability

`Post` is readonly, so a post you have handed to the publisher cannot be changed under you. To vary content per network, build a second `Post` rather than mutating the first.
