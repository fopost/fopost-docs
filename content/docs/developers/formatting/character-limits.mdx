# Character Limits

Each formatter knows its network's limit and trims to it on a word boundary, with an ellipsis. You do not truncate by hand.

## Platform character limits

| Platform | Max Characters |
|:---------|:--------------|
| Twitter/X | 280 |
| Pinterest | 800 |
| Discord | 2,000 |
| Instagram | 2,200 |
| LinkedIn | 3,000 |
| Telegram | 4,096 |
| Tumblr | 4,096 |
| WhatsApp | 4,096 |
| Reddit | 40,000 |
| Slack | 40,000 |
| Facebook | 63,206 |

## How truncation works

- Breaks at **word boundaries**, never mid-word
- Appends an **ellipsis**, counted against the limit so the result is never one over
- Budgets for the hashtags and the canonical URL before trimming the body
- On X, budgets for the fixed width every URL is wrapped to, whatever its real length

Read a network's limit at runtime rather than hardcoding one:

```php
$formatter->maxLength();              // 280
$platform->constraints();             // limits, media types, sizes
```

Networks change these. Reading them is one call and never goes stale.

## Which field gets cut

The body. `title`, the canonical URL, and as many hashtags as fit are preserved, on the reasoning that a trimmed sentence still reads while a broken link does not. Set `excerpt` on the post to control what a tight network shows instead of leaving it to the truncator.
