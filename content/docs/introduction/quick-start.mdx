# Quick Start

Three starting points. Pick the one that matches what you are doing.

## Using the dashboard

1. Sign up at [app.fopost.com](https://app.fopost.com). Every plan starts with a trial
2. **Accounts → Connect** and authorise one network
3. **New Post**, write it, tick the account, check the preview
4. **Publish**, or **Schedule** for later

## Using the API

Create a key at **Settings → API Keys** with the `posts` and `accounts` scopes.

```bash
# Find an account to post to
curl https://api.fopost.com/v1/accounts \
  -H "X-API-Key: $FOPOST_API_KEY"

# Create a post
curl -X POST https://api.fopost.com/v1/posts \
  -H "X-API-Key: $FOPOST_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "workspace_id": "7d2b8c11-4e5a-4a8f-b0d9-3c5e6f7a8b90",
    "accounts": ["3a9f1d20-6c77-4b2e-9a01-8f5d2c3b4e10"],
    "content": [{ "text": "Hello from the API." }]
  }'

# Publish it
curl -X POST https://api.fopost.com/v1/posts/$POST_ID/publish \
  -H "X-API-Key: $FOPOST_API_KEY"
```

Or with a client:

```ts
import { FoPost } from '@fopost/sdk';

const owl = new FoPost({ apiKey: process.env.FOPOST_API_KEY! });
const post = await owl.posts.create({ workspaceId, accounts, content: [{ text: 'Hello' }] });
await owl.posts.publish(post.id);
```

```python
from fopost import Fopost

client = Fopost()
post = client.posts.create(workspace_id=ws, accounts=ids, content="Hello")
client.posts.publish(post.id)
```

## Using the PHP library

No account needed. It publishes from your server with credentials you hold.

```bash
composer require fopost/fopost-social-core
```

```php
use Fopost\Core\Config\PlatformCredentials;
use Fopost\Core\Content\Post;
use Fopost\Core\Http\HttpClient;
use Fopost\Core\Platforms\PlatformRegistry;
use Fopost\Core\Platforms\Telegram\TelegramFormatter;
use Fopost\Core\Platforms\Telegram\TelegramPlatform;
use Fopost\Core\Publishing\Publisher;

$credentials = new PlatformCredentials('telegram', [
    'api_token' => getenv('TELEGRAM_BOT_TOKEN'),
    'channel_username' => '@your-channel',
]);

$registry = new PlatformRegistry();
$registry->register(new TelegramPlatform($credentials, new HttpClient(), new TelegramFormatter()));

$result = (new Publisher($registry))->publish(
    new Post(title: 'Hello World', body: 'My first post via Fopost.'),
    'telegram',
);

echo $result->success ? $result->externalUrl : $result->error;
```

## Which one

The library talks to eleven networks with your own credentials and is free. The Cloud talks to thirty, schedules, retries, measures, and gives you a dashboard. They are separate products, and [What is FoPost?](/what-is-fopost) has the comparison.
