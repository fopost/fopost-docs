# Welcome to OwlStack

**OwlStack** publishes, schedules, and manages content across 30 social networks, from one place.

Use the dashboard if you are a creator or a team. Use the API if you are building something.

## For creators and teams

No code. The [dashboard](/guide/using-owlstack/dashboard) does all of it.

- **Publish everywhere at once.** Write once, with a native version per network and a live preview of each
- **Schedule ahead.** A calendar you can drag, bulk import from a spreadsheet, and best times worked out from your own data
- **The [Owl Agent](/guide/using-owlstack/owl-agent).** Ask for a campaign in plain language, review the drafts, approve what ships
- **Automate the repetitive parts.** Feeds, webhooks, and recycling your evergreen winners
- **Measure it.** Engagement, followers, top posts, and campaign roll-ups by label
- **Work as a team.** Workspaces with real isolation, roles, and approvals

## For developers

Two different things, and it is worth knowing which you want.

**The [Cloud API](/api/overview)** is the product behind the dashboard. One REST API for every network, with scheduling, media, analytics, automations, and webhooks. Official clients for [TypeScript](/sdks/typescript), [Python](/sdks/python), and [MCP](/sdks/mcp).

**The [PHP library](/developers)** is a free, MIT-licensed package that publishes straight to eleven networks from your own server, with credentials you hold. No account, no API key, nothing through us. There are [Laravel](/sdks/laravel/installation) and [WordPress](/sdks/wordpress/installation) wrappers.

## Clients

| Client | Status |
|:-------|:-------|
| [TypeScript / Node.js](/sdks/typescript) | Available, `@owlstackapp/sdk` |
| [Python](/sdks/python) | Available, `owlstack` |
| [MCP server](/sdks/mcp) | Available, `@owlstackapp/mcp` |
| [PHP library](/developers) | Available, `owlstack/owlstack-core` |
| [Laravel](/sdks/laravel/installation) | Available, `owlstack/owlstack-laravel` |
| [WordPress](/sdks/wordpress/installation) | Available, plugin |
| [Browser extension](/sdks/browser-extension) | Available |

No Go, Ruby, or Rust client yet. The [REST API](/api/overview) works from any language in the meantime.
