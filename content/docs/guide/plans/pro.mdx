# Pro

**$39/mo**, or **$372/year**. The most popular plan.

For a small team, or one person running several brands.

## What you get

| | |
|:--|:--|
| Social accounts | 25 |
| Networks | Every one |
| Posts | Unlimited |
| AI credits | 750/mo |
| Media storage | 25 GB |
| Workspaces | 3 |
| Team members | 3 |
| Link in Bio pages | 5 |
| Analytics | Advanced |
| Support | Priority |

## Everything in Starter, plus

- **Brand voices.** Define tone, style, colours, and fonts once, and AI holds to them across everything it writes and generates
- **Blog and URL to social.** Paste a URL and get a native post per network
- **Advanced analytics.** Trends, best-performing content, cross-network comparison, best send times from your own data
- **API access.** The full [REST API](/api/overview), plus the [TypeScript](/sdks/typescript), [Python](/sdks/python), and [MCP](/sdks/mcp) clients
- **Three workspaces**, so clients or brands stay isolated
- **Three seats**, with roles per workspace
- **Priority support**

## Growing past it

- Extra workspaces at $19/mo each
- Extra seats at $8/mo each

At around ten accounts or ten people, [Business](./business) is cheaper than the add-ons.
