# Sources

A source is something the workspace keeps to write from: an article, a pasted brief, a document, a talk. It outlives the post it first produced, so the same product page can generate three posts on three different days without being supplied again.

## What you can add

| Type | What happens |
|:-----|:-------------|
| **URL** | The page is fetched and the readable text extracted |
| **Text** | Pasted directly. A brief, notes, a positioning doc |
| **File** | A document, read into text |
| **Video** | Transcribed, and the transcript becomes the source |

Extraction costs AI credits. Reusing a source afterwards does not.

## Why keep them

The alternative is pasting the same brief into the composer every time, which means the wording drifts and nobody can tell which version a post was written from. A shelf keeps the raw material in one place and lets the agent cite what it used.

## Using one

Pick sources when asking the [agent](./agent) for content. A single generation can draw on up to five, which is enough to write a launch post from a product page, a positioning doc, and a transcript at once.

## Usage

Each source shows what has been made from it. Handy for noticing a webinar transcript has produced eleven posts and is probably exhausted.

## Sources and brands

A source is the **what**. A [brand](./brand-voices) is the **how**. Give the agent both and you get content that is about the right thing and sounds like you.
