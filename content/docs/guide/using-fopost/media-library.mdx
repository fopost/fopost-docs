# Media Library

Upload once, use everywhere. The library is per workspace, so a client's assets never appear in another client's picker.

## Adding files

Drag them in, or import from a connected source. Up to 50 MB per file. Images, video, GIFs, and documents.

An import is an upload in every way that matters: same checks, same library, same reuse. It does not create a second class of file that behaves differently.

## Alt text, written for you

AI describes each image on upload and the description is editable. It is what screen readers announce, several networks surface it, and almost nobody writes it by hand.

## Search

Search by filename, by the AI description, or by tag. Which means you can find "the one with the blue chart" without having named it that.

## Folders

Organise into folders per workspace. Optional: search usually beats structure, but a folder per campaign is easier to hand to someone else.

## Per-network sizing

Attach a file and it is resized and cropped for each target network's aspect ratio. Adjust the crop per network when the automatic one cuts the wrong thing.

## Usage history

Each asset shows where it has been used and when. Useful for noticing you have posted the same image three times this month, and for finding every post using a photo you have lost the rights to.

## Storage

The library counts against your plan's storage: 5 GB on Starter, 25 GB on Pro, 100 GB on Business. Deleting a file frees the space; posts already published keep their copy on the network.

## Privacy

The bucket is private. Files are served through a per-request check against your workspace membership, so a URL copied out of the dashboard is not a public link that works forever.

## Sources, not media

Articles, briefs, and transcripts the [agent](./agent) writes from live in [Sources](./sources), not here. Media is what goes on the post; a source is what the post is about.
