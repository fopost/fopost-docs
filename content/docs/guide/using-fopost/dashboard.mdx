# Dashboard Overview

The dashboard at [app.fopost.com](https://app.fopost.com) is organised around what you do daily, with configuration tucked into Settings.

## The top of the sidebar

| | |
|:--|:--|
| **Overview** | Recent activity, what is scheduled next, and how the accounts are doing |
| **[Agent](./agent)** | The chat surface. Ask for a campaign, get drafts back |
| **[Inbox](./inbox)** | Comments and mentions from every connected account, in one list |

## Publishing

| | |
|:--|:--|
| **[Calendar](./calendar)** | Everything scheduled and published, as a month or a week. Drag to reschedule |
| **[Posts](./creating-posts)** | The list. Drafts, scheduled, published, failed |
| **[Recycling](./recycling)** | Evergreen posts that go out again on a cadence, with fresh variants |
| **[Automations](./automations)** | Rules that publish without you: a feed, a webhook, a schedule |

## Library

| | |
|:--|:--|
| **[Media](./media-library)** | Images and video, with AI alt text and search |
| **[Sources](./sources)** | Articles, briefs, and transcripts the agent draws from |
| **[Brands](./brand-voices)** | Tone, style, colours, fonts, and brand assets |
| **Collections** | Named groups of posts and media, for a launch or a client |

## Insights

| | |
|:--|:--|
| **[Analytics](./analytics)** | Engagement, followers, top posts, best times |
| **Competitors** | Public accounts you track, next to your own numbers |

## Channels

| | |
|:--|:--|
| **[Accounts](./connecting-accounts)** | Connect, reconnect, and check the health of each |
| **[Link in Bio](./link-in-bio)** | Your bio page and its click analytics |

## Settings

Billing and plan, AI usage, team and invitations, workspaces, labels, API keys, webhooks, and notifications.

**AI Usage** is where you see how many credits are left in the period.

## Switching workspace

The workspace switcher is at the top of the sidebar. Each workspace is a separate world: its own accounts, posts, media, analytics, and members. Nothing crosses between them. See [Workspaces](./workspaces).
