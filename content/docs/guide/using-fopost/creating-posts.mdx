# Creating Posts

Click **New Post** from anywhere.

## Type once

Write the post in the editor. As you type, a preview renders for each account you have selected, showing the post as that network will actually display it: the truncation, the line breaks, the link preview, the image crop.

That preview is the point of the composer. Most bad posts are not badly written, they are badly cut.

## Pick the accounts

Tick the accounts, not the networks. Three X accounts in a workspace are three separate targets, and the composer will not guess.

## Override per network

Anything that should differ, you change in place. A shorter version for X, a different opening for LinkedIn, a different image for Instagram. Everything unedited keeps following the main text, so a late fix to the shared copy still reaches every network.

## Media

Drag files in, or pick from the [media library](./media-library). Images are cropped to each network's aspect ratio automatically, and you can adjust per network when the automatic crop cuts the wrong thing.

Alt text is generated for uploads, and editable. It is what screen readers announce, and several networks surface it.

## Hashtags

Type them, or let AI suggest a set that fits the network: what reads as normal on Instagram reads as spam on LinkedIn. Suggestions cost AI credits; typing them does not.

## Threads

More than one block makes a thread on networks that support them. On networks that do not, the blocks are joined into one post.

## Per-network settings

Some networks need more than text. Reddit needs a subreddit and often a flair, Pinterest needs a board, YouTube and TikTok need video settings. Those appear as their own controls when you select an account that needs them, so you cannot schedule something that will be rejected on arrival.

## Before publishing

The composer flags two kinds of thing:

- **Blockers**, which stop publishing: content over the limit, a media type the network refuses, a missing required field
- **Suggestions**, which do not: a post with no image on a visual network, a link with no context, a first line that will be cut in the feed

Blockers must be fixed. Suggestions are advice, and you can ignore them.

## Publish, schedule, or save

**Publish** sends it now. **Schedule** puts it on the [calendar](./calendar). **Save as draft** keeps it, and drafts are never lost to a closed tab.

## After publishing

Each account gets its own status and a link to the live item. A failure shows the reason and a **Retry** that resends only the failed account, so a working post is not published twice.
