# Link in Bio

One link in a profile, pointing at a page you control.

## Build it

**Link in Bio → New page**. Add blocks and drag them into order:

- Links
- Text and headings
- Images and video
- Your latest post, which updates itself as you publish
- Social icons

Mobile first, since that is where every visitor arrives from.

## Themes

Start from a theme and edit the colours and fonts, or pull them from a [brand](./brand-voices) so the page matches everything else you publish. Not a preset you have to live inside.

## Your own domain

Point a custom domain at the page and the certificate is issued and renewed automatically. A branded link beats a shared one on someone else's domain, and it means the URL survives if you ever move.

Without a custom domain, the page lives on the shared bio domain.

## Analytics

Clicks per block, not just visits to the page. That tells you which link is doing the work and which one has been dead for six months.

## Latest post block

Publish anywhere in OwlStack and the block updates. One less page to maintain by hand.

## How many

One page on Starter, five on Pro, twenty-five on Business.

The cap is there because bio pages are public and carry arbitrary outbound links, which makes an uncapped account a spam vector against the shared domain. It is not an upsell lever.
