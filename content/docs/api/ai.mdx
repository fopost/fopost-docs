Most AI in FoPost runs inside the dashboard and the [FoPost Agent](/guide/using-fopost/agent), where a person is in the loop. Two endpoints are reachable with an API key, both under the `ai` scope.

The `ai` scope is deliberately separate from every other scope, because it is the only one that spends money. A key that can publish cannot generate unless you also grant `ai`.

## Generate a caption

```http
POST /v1/ai/generate-caption
```

```bash
curl -X POST https://api.fopost.com/v1/ai/generate-caption \
  -H "X-API-Key: $FOPOST_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "content": "Notes from our launch week retro" }'
```

Writes or improves a caption. It costs AI credits.

## Credit balance

```http
GET /v1/ai/credits
```

What is left in the current period. Read it before a batch job so you fail early instead of halfway through.

## Running out

An AI call with no credits left answers `402`, with an `upgrade_url` in the body. It is not a rate limit, so do not retry it with backoff. Either top up, or degrade to publishing without generation.

Credits reset with the billing period. One-time top-ups do not expire with it and are spent after the monthly allowance. See [Plans](/guide/plans/overview).

## Everything else

Rewriting for each platform, hashtags, turning a URL into posts, voice notes, alt text, and image and video generation are dashboard and agent features and are not exposed to API keys. They are documented in the [guide](/guide), not here.
