Bluesky connects with an app password, not OAuth, and works against any PDS: the default `bsky.social` or a self-hosted server.

## Connecting

Create an app password in Bluesky under **Settings → App Passwords**, then enter your handle and that password in **Accounts → Connect → Bluesky**. Never use your account password. Running your own PDS? Point the connection at your server's address instead of the default.

## What you can publish

| Limit | Value |
|:------|:------|
| Post length | 300 characters |
| Images | Up to 4 (JPEG, PNG, WebP, or GIF), 2 MB each |
| Video | One MP4, up to 300 MB and 3 minutes |
| Alt text | Supported per item |

A post carries images **or** one video, never both. The composer enforces it so Bluesky does not reject the post. Links, mentions, and hashtags in the text become rich facets automatically, and a post with a link but no media gets a link preview card. A link only costs its own characters.

Thread chains are supported: blocks written as a thread publish as replies to each other.

Video goes through Bluesky's processing pipeline, and FoPost waits for it to finish before publishing. Bluesky applies its own daily video quotas and requires a verified email for video upload. Those are Bluesky's rules, surfaced as the post's error message when they bite.

## Post languages

Bluesky filters the feed by language, so a post with none set is shown to everyone regardless of what they read. The composer picks up to three BCP-47 tags per post, and each connection carries a default the composer starts from.

```bash
# Read the connection default
curl https://api.fopost.com/v1/accounts/{account_id}/bluesky/languages \
  -H "X-API-Key: $FOPOST_API_KEY"

# Set it; an empty list clears it
curl -X PUT https://api.fopost.com/v1/accounts/{account_id}/bluesky/languages \
  -H "X-API-Key: $FOPOST_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"languages": ["en", "pt-BR"]}'
```

Per post, pass the same tags as the `languages` platform setting.

## Analytics

Per post: likes, replies, and reposts plus quotes. Per account: followers, following, and post count. Recent posts published natively in a Bluesky app are included in [analytics](/guide/analytics) too. Competitor tracking works on Bluesky: track any public handle.

## Inbox

Replies and mentions land in the [inbox](/guide/inbox), and you can reply from there.

## Deleting

Deleting the post in FoPost deletes it on Bluesky.
