A Dribbble post is a **shot**: one image with a title, a description, and tags.

## Connecting

**Accounts → Connect → Dribbble**, approve on Dribbble. Uploading shots requires an account Dribbble allows to post shots — a Player or Team account, per Dribbble's own rules. Tokens do not expire.

## What you can publish

| Limit | Value |
|:------|:------|
| Image | Exactly one — GIF, JPG, or PNG, up to 8 MB. Required |
| Title | Required — from the post title, or the first line of the body |
| Description | Up to 4,000 characters |
| Tags | Up to 12 |
| Video and links | Not supported |

Dribbble processes shots asynchronously, so the shot may take a moment to appear after a successful publish.

## Analytics

Dribbble's current API no longer exposes per-shot views or likes, so post metrics are empty. Account-level: followers, following, and shot count.

## Deleting

Deleting the post in FoPost deletes the shot.
