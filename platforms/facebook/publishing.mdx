## Post shapes

Picked automatically from what the post carries:

- **Video post** — the post's video, with the text as its description
- **Single photo** — one image with the text
- **Multi-photo** — up to 10 images in one post
- **Text or link post** — the text, with the post's link rendered as Facebook's link preview

## Limits

| Limit | Value |
|:------|:------|
| Text | 63,206 characters |
| Images | Up to 10 (JPEG, PNG, or GIF), 10 MB each |
| Video | MP4, up to 1 GB and 90 seconds |
| Link | On text posts, becomes the link preview |

Hashtags typed in the text work as normal; Facebook has no separate tag field.

## Deleting

Deleting the post in FoPost deletes it from the Page.
