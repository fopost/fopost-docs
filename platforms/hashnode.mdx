Hashnode publishing creates an article in your publication.

## Connecting

**Accounts → Connect → Hashnode**, paste a Personal Access Token from Hashnode's developer settings and name your publication. A publication is required (Hashnode's API does not publish to a bare profile), and API access is a Hashnode Pro feature, which is Hashnode's own requirement.

## What you can publish

| Limit | Value |
|:------|:------|
| Body | 100,000 characters, delivered as Markdown |
| Title | From the post title, or the start of the body |
| Tags | Up to 5 |
| Canonical link | The post's link becomes the article's original-article URL |
| Images | Up to 10, by URL, 25 MB each |

The first attached image not already placed in the body becomes the article's **cover image** (or set one explicitly per post); remaining images are appended to the article. Articles publish live; there is no draft option on Hashnode today.

## Analytics

Per article: views, reactions, and comments. Account-level: follower and article counts. Articles written natively on Hashnode are included in [analytics](/guide/analytics). Competitor tracking works: track any public Hashnode publication by its host.

## Inbox

Comments and replies on your publication's recent articles land in the [inbox](/guide/inbox), and you can reply from there.

## Deleting

Deleting the post in FoPost deletes the article on Hashnode.
