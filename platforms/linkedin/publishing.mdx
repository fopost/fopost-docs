## Post shapes

Picked from what the post carries, in this order:

- **Video**: one video with the text
- **Document**: a PDF attached to the post, LinkedIn's native document viewer
- **Carousel**: turn on *post as carousel* and multiple images publish as one swipeable document, with an optional carousel title
- **Multi-image**: up to 20 images in one post
- **Single image**
- **Link post**: the post's link as LinkedIn's preview card, with the post text above it
- **Text only**

Per post you can set **visibility**: public, or connections only.

## Limits

| Limit | Value |
|:------|:------|
| Text | 3,000 characters, hashtags appended |
| Media | Up to 20 items |
| Image size | 10 MB (JPEG, PNG, or GIF) |
| Video | MP4, up to 500 MB and 30 minutes |
| Documents | PDF |
| Alt text | Up to 4,086 characters per image |

## Mentions

LinkedIn renders a mention only when the text carries the entity's URN, in the form `@[Devtestco](urn:li:organization:2414183)`. The composer searches organizations and hands you that snippet to paste.

Turn on **Turn @names into LinkedIn mentions** and each `@name` in the post is looked up when it publishes. One that resolves becomes a mention under the organization's own name; one that does not stays exactly as you typed it. The switch is off unless you set it, so an ordinary `@` in a sentence is never turned into a link behind your back.

```bash
curl "https://api.fopost.com/v1/accounts/{account_id}/linkedin/mentions?q=devtestco" \
  -H "X-API-Key: $FOPOST_API_KEY"
```

Over the API, set `resolve_mentions` to `true` in the post's LinkedIn platform settings, or write the `@[Name](urn)` form yourself and leave the switch off.

People cannot be searched: LinkedIn has no public person search, so a member mention has to be written with a URN you already hold.

## No native articles

LinkedIn has no API for authoring articles: that is LinkedIn's gap, not a toggle. A post composed as an article reaches LinkedIn as its companion link post: title, description, and link card pointing at the article's home.

## Deleting

Deleting the post in FoPost deletes it on LinkedIn.
