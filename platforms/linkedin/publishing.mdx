## Post shapes

Picked from what the post carries, in this order:

- **Video**: one video with the text
- **Document**: a PDF attached to the post, LinkedIn's native document viewer
- **Carousel**: turn on *post as carousel* and multiple images publish as one swipeable document, with an optional carousel title
- **Multi-image**: up to 20 images in one post
- **Single image**
- **Link post**: the post's link as LinkedIn's preview card, with the post text above it
- **Text only**

Per post you can set **visibility**: public, or connections only.

## Limits

| Limit | Value |
|:------|:------|
| Text | 3,000 characters, hashtags appended |
| Media | Up to 20 items |
| Image size | 10 MB (JPEG, PNG, or GIF) |
| Video | MP4, up to 500 MB and 30 minutes |
| Documents | PDF |
| Alt text | Up to 4,086 characters per image |

## No native articles

LinkedIn has no API for authoring articles: that is LinkedIn's gap, not a toggle. A post composed as an article reaches LinkedIn as its companion link post: title, description, and link card pointing at the article's home.

## Deleting

Deleting the post in FoPost deletes it on LinkedIn.
