DEV.to publishing creates an article from your post.

## Connecting

**Accounts → Connect → DEV.to**, paste an API key generated in your DEV.to settings.

## What you can publish

| Limit | Value |
|:------|:------|
| Body | 100,000 characters, delivered as Markdown |
| Title | From the post title, or the start of the body |
| Tags | Up to 4, DEV.to's own ceiling |
| Canonical link | The post's link becomes the article's canonical URL |
| Media | Not uploaded; images must be URLs in the body |

Per post you can publish live (the default) or as a **draft** on DEV.to.

## Analytics

Per article: page views, reactions, and comments. Account-level: follower and article counts. Articles published directly on DEV.to are included in [analytics](/guide/using-fopost/analytics). Competitor tracking works: track any public DEV.to author.

## Inbox

Comments on your recent articles land in the [inbox](/guide/using-fopost/inbox). DEV.to's API cannot post comments, so replying happens on DEV.to itself. The inbox links you straight to the thread.

## Deleting

DEV.to's API has no delete. Deleting the post in FoPost **unpublishes** the article: it returns to drafts on DEV.to rather than disappearing.
