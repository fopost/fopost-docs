MeWe posts go to your own profile, through MeWe's developer API.

## Connecting

**Accounts → Connect → MeWe** sends you to MeWe's login to approve the connection. MeWe issues a token with an expiry and no refresh, so when it lapses the account shows as expired in **Accounts** and one click reconnects it.

## What you can publish

| Limit | Value |
|:------|:------|
| Post length | 60,000 characters — MeWe documents no hard limit, so this is a generous ceiling |
| Photos | Up to 10 (JPEG, PNG, or GIF), 10 MB each |
| Video | Not supported — MeWe's API has no video upload |
| Links and tags | Not supported as separate fields — write them into the text |

A post needs text or at least one photo.

## What MeWe does not give back

MeWe's API returns no post ID on publish, so FoPost can confirm the post went out but cannot link you to it — open MeWe to see it. For the same reason there are **no analytics** and **no deletion** from FoPost; manage published posts in MeWe itself.
