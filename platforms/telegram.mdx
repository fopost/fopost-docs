Telegram works through our bot: it posts into the chat you connect, and messages sent to it in that chat land in your inbox.

## Connecting

Connect with a one-time code, so there is no chat ID to look up.

1. Open **Connections → Telegram** and choose **Connect with Code**.
2. Send the command shown, `/connect <code>`, in the chat you want to connect:
   - **Private chat:** tap **Open Private Chat**, which opens the bot with the code filled in.
   - **Group:** tap **Add to Group**, pick the group, and the code goes with it. Make the bot an admin if it should post.
   - **Channel:** add the bot as an admin with permission to post, then post the command in the channel. The bot removes the command message once it has read it.
3. The dialog closes once the chat is connected. The code works once and expires after 15 minutes.

A public channel can still be connected by its `@username` from the same dialog.

Over the API, `POST /v1/accounts/telegram/connect-code` returns the code and both links, and `GET /v1/accounts/telegram/connect-code/status?code=<code>` reports `pending`, `connected` (with the account ID), `failed` (with a reason) or `expired`.

## What you can publish

| Limit | Value |
|:------|:------|
| Text message | 4,096 characters |
| Caption with media | 1,024 characters: the caption limit governs the moment media rides along |
| Media per post | Up to 10 photos or videos, as an album |
| Photo size | 10 MB |
| Video size | MP4, up to 50 MB |

Posts render with formatting: a bold title, the body, a **Read more** link when the post has one, and hashtags. One photo or video sends as a single captioned message; several send as an album with the caption on the first item.

Per post you can send **silently** (no notification sound) and **protect content** (no forwarding or saving), the same options Telegram offers.

## Inbox

Messages sent to the bot in a connected private chat or group appear in **Inbox → Messages**, and your reply is sent back into the chat as a reply to that message. Replies carry text only.

In groups, Telegram only passes the bot commands, replies to its own messages and messages that mention it, unless the group makes the bot an admin. Channels have no inbox.

Photos, files and voice notes show as a message without their content, since the bot cannot share those files outside Telegram.

## Bot commands

The account drawer in **Connections** has a **Bot Commands** editor for private chats and groups: the menu Telegram shows when someone types `/` in that chat. Up to 100 commands, each 1 to 32 lowercase letters, digits or underscores, with a description of up to 256 characters. The menu applies to the connected chat only.

Over the API: `GET`, `PUT` and `DELETE /v1/accounts/{id}/telegram/commands`.

## Analytics

The Bot API exposes no per-message metrics, so post analytics are empty; the member count of the channel or group is read back as the follower number.

## Deleting

Deleting the post in FoPost deletes the message from the channel.
