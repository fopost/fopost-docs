Medium publishing creates an article from your post, on your profile or in a publication.

## Connecting

**Accounts → Connect → Medium**, paste an integration token from Medium's security settings. Medium stopped issuing new integration tokens in 2023, so connecting requires a token you already have — existing tokens keep working. If the connection names a publication, articles go there; otherwise they go to your profile.

## What you can publish

| Limit | Value |
|:------|:------|
| Body | 100,000 characters, delivered as Markdown |
| Title | From the post title, or the start of the body |
| Tags | Up to 5 |
| Canonical link | The post's link becomes the article's canonical URL |
| Media | Not uploaded — images must be URLs in the body |

Per post you can publish as **public** (the default) or as a **draft** on Medium. Followers are notified on publish, per Medium's own behaviour.

## Analytics and deletion

Medium's API exposes neither stats nor deletion, so there are no analytics and no deletion from FoPost — manage published articles on Medium.
